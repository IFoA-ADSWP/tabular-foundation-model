# legacy/ — Deprecated R analysis scripts

This directory holds the original R analysis scripts from the early phase of the ADSWP project
(`adswp_project_scripts/`). They are retained for historical reference only.

- Not part of the current analysis path.
- Numbers from these scripts are v2-era and must not be cited without a version stamp (see
  `docs/MODEL_VERSIONS.md`).
- The current Python analysis path is `src/` + `notebooks/` + `scripts/`; see
  `CONTRIBUTING.md` for the contribution map.

If you need to resurrect any of this work, port it to the Python path rather than extending the R scripts.
